## 设备接入阶段（REQ9/AC9）
REQ9 用户可在控制台绑定自己的机器人设备并下发指令；AC9 绑定后设备能完成鉴权与状态上报，控制台显示在线状态，下发指令在数秒内被执行且可查看结果，设备密钥仅显示一次并可随时吊销，跨账号不可见。
REQ11 唤醒词可自定义：用户可在控制台为每台设备指定唤醒词（中文或拼音），设备收到后**运行时生效**（无需重启）并写入 NVS，重启后仍是新词；模型不接受的词必须被拒绝且**保留原词**（不能把设备变成聋子），原因回报到控制台。AC11 控制台下发后设备在数秒内生效并回报结果；喊新词可唤醒、旧词不再唤醒；断电重启后仍是新词；下发无效词时设备仍能用旧词唤醒且回报失败原因。（2026-10-15 用户提出并当日完成：固件侧运行时换词 + NVS 持久化，控制台填中文由服务端转拼音下发并展示设备回报值；真机/浏览器验收待做。）
REQ10 语音交互：喊唤醒词即可与机器人对话，且**再说一次唤醒词能打断它正在说的回答**；AC10 唤醒词触发一轮云端对话（离线唤醒引擎工作正常，串口出现 `offline wake word detected`）；回答播放期间麦克风与唤醒引擎仍在工作，唤醒词被听到后回复流被切断并立刻进入下一轮聆听；一轮回答播完后不必再喊唤醒词即可接着说下一句，安静超过窗口时长（默认 4 秒）则结束这段对话回到离线待机；BOOT 短按仍可打断（语义是"结束这段对话"）。（2026-10-15 用户提出，同日实现，真机待验。）
本期设备通道采用 HTTP 轮询而非长连接：Cloudflare Workers 无法把一次 HTTP 请求的消息推送到另一个 WebSocket 连接，推送需要 Durable Objects，属于后续按需评估项，当前不引入。
