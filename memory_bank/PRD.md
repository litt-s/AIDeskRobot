## 目标
中文机器人控制台，电脑、平板、手机共用账户和数据；本期无语音、无设备控制。
## 功能与验收
REQ1/AC1 公开注册登录退出，PBKDF2 密码，隔离用户数据。REQ2/AC2 模型增删改、密钥加密及掩码、连接测试。REQ3/AC3 角色 system 提示词、任务及关联模型。REQ4/AC4 OpenAI 兼容真实流式聊天、历史持久化。REQ5/AC5 360/390/768/1024/1440 中文浅色无遮挡界面。REQ6/AC6 本地迁移、构建、检查及 GitHub/Cloudflare 部署准备。
REQ7/AC7 生成中可暂停并保存已生成内容，暂停后可继续生成：继续时把新内容追加到同一条回复、不重复插入用户提问；刷新或重新打开页面后可恢复该状态并继续；旧请求不能覆盖或删除新请求的状态。
REQ8/AC8 聊天交互体验：回车发送、Shift+回车换行且中文输入法组合态不误发；发送与生成时消息区自动跟随最新，用户上滑查看历史时停止跟随、滑回底部恢复；续写时在中断处显示"继续生成中"；最后一条提问下方可撤销该轮对话，删除该提问及其回复并把问题文本回填输入框。

## 设备接入阶段（REQ9/AC9）
REQ9 用户可在控制台绑定自己的机器人设备并下发指令；AC9 绑定后设备能完成鉴权与状态上报，控制台显示在线状态，下发指令在数秒内被执行且可查看结果，设备密钥仅显示一次并可随时吊销，跨账号不可见。
REQ10 语音交互：喊唤醒词即可与机器人对话，且**再说一次唤醒词能打断它正在说的回答**；AC10 唤醒词触发一轮云端对话（离线唤醒引擎工作正常，串口出现 `offline wake word detected`）；回答播放期间麦克风与唤醒引擎仍在工作，唤醒词被听到后回复流被切断并立刻进入下一轮聆听；一轮回答播完后不必再喊唤醒词即可接着说下一句，安静超过窗口时长（默认 4 秒）则结束这段对话回到离线待机；BOOT 短按仍可打断（语义是"结束这段对话"）。（2026-10-15 用户提出，同日实现，真机待验。）
本期设备通道采用 HTTP 轮询而非长连接：Cloudflare Workers 无法把一次 HTTP 请求的消息推送到另一个 WebSocket 连接，推送需要 Durable Objects，属于后续按需评估项，当前不引入。
