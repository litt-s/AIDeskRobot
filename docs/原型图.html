语音链路说明

  • 设备上传完整 PCM（16 kHz / 16 bit / 单声道），上限 30 秒。
  • 服务端依次完成：ASR 转写 → 角色模型流式回复 → 按句 TTS → 边合成边下发。
  • 事件与音频共用一条流，任何一步失败都会下发 error + done，设备不会只看到断线。
  • 每轮对话自动写入设备专属会话，失败也会留痕，可在「对话」页回看。
  • 流式回复：分块上传 与 整段上传 可由设备按网络质量切换。

凭据来源优先级

  1. 本账户凭据（绿色横幅显示）
  2. 平台默认凭据（蓝色横幅显示）
  3. 无可用凭据（机器人会回报"未配置语音服务"）

多端共享原则

  • 所有端访问同一套 /api/*，数据按 user_id 严格隔离。
  • 客户端外壳只负责承载与网络，不复制业务逻辑。
  • 模型密钥、语音凭据只在服务端解密，任何端都不落明文。
  • 同一份 UI、同一份数据，切换端的体验是"无缝的"。

首次启动差异

  • 网页：直接进入登录页，登录后进入工作台。
  • Android：先选服务器地址（Cloudflare/腾讯 CloudBase/局域网），再进入控制台。
  • Windows：默认本机形态（自拉 Node 后端），环境变量 AIDESK_SERVER_URL 可切远端。
  • 小程序：填写服务地址 → 登录或注册 → 进入工作台（带 X-Aidesk-Client: miniprogram 请求头）。

字体

中文：系统微软雅黑 / 苹方；数字与代码：SF Mono / Consolas。标题清晰紧凑，正文 14px / 行高 1.55。

布局

  • 桌面：左侧导航 200px + 主工作区，移动：横向导航 + 列表自动折叠。
  • 所有内容左对齐；机器人轮廓作为空会话的唯一视觉焦点，不放统计卡片。
  • 五个目标宽度：360 / 390 / 768 / 1024 / 1440，必须无水平溢出与遮挡。

交互原则

  • 输入框回车发送，Shift+回车换行；中文输入法组合态不触发发送。
  • 消息区自动跟随最新；上滑离开底部即停跟随，回到底部恢复。
  • 生成中按钮三态互斥：发送 / 暂停（处理中显示"保存中"）/ 继续。
  • 生成中锁定：禁止新提问与角色切换；撤销/重新生成需先暂停。
  • 设备密钥一次性显示：XXXX-XXXX-XXXX，可省横线、不分大小写。
  • 设备页/对话页停留时每 3 秒只读轮询；后台标签页停止。
  • 失败/删除/解绑等关键操作都需二次确认（confirm 弹窗）。

可访问性

  • 弹窗使用 role="dialog" + aria-modal="true"，ESC 关闭。
  • 所有图标按钮有 aria-label 或可见文字。
  • 错误信息 role="alert"，表单字段有关联的 label。
  • 键盘焦点可见，不被 tabindex 强行改写顺序。
