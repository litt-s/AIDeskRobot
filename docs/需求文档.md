# AIDesk 机器人控制台 · 需求文档

> 版本 v1.0 · 2026-10-16 · 基于 memory_bank 九文档整理

## 1 背景

AIDesk 是一个桌面机器人的云端控制台。用户通过网页/Android/Windows/小程序四种客户端，管理自己的 AI 模型、角色、对话、设备与语音链路，远程批准 Codex 请求，生成并管理会议纪要。

## 2 目标

- 中文优先的机器人工作台，电脑、平板、手机共用账户和数据。
- 完整闭环：注册登录 → 连接模型 → 设定角色 → 开始对话 → 绑定设备 → 语音交互 → 会议纪要 → Agent 远程批准。

## 3 功能需求

### FR1 账户与认证
- 公开注册登录退出；PBKDF2 加盐密码；HttpOnly Cookie 或 Bearer token 会话；CSRF origin 检查；合理限流。
- 所有业务数据按 user_id 严格隔离，跨租户 ID 返回 404。

### FR2 模型连接
- 支持任意 OpenAI 兼容 API；CRUD；密钥 AES-GCM 加密存储，API 只返回掩码（sk-••••7f2a）。
- 连接测试返回安全摘要（超时/网络/协议/HTTP 状态），不泄露上游响应头或密钥。

### FR3 角色设定
- 每个角色有系统提示词 + 任务说明 + 关联模型；CRUD；一台设备可绑定一个语音角色。

### FR4 对话工作台
- 流式回复（SSE）；消息持久化。
- 生成中可暂停并保存已生成内容，暂停后可继续：追加到同一条回复、不重复插入用户提问；刷新或重新打开页面后可恢复。
- 回车发送、Shift+回车换行；中文输入法组合态不误发。
- 消息区自动跟随最新，用户上滑停止跟随、回到底部恢复。
- 最后一条提问下方可撤销（删除该轮并把问题回填输入框）或重新生成（替换回复、保留提问）。
- 生成中禁用新提问与角色切换。

### FR5 设备管理
- 绑定设备：填设备名后签发一次性 12 位短密钥（XXXX-XXXX-XXXX），可省横线、不分大小写；关闭弹窗后不可再查看。
- 设备以密钥鉴权（服务端只存哈希与掩码），通过 /api/device/* 握手、轮询指令并回报结果。
- 控制台显示在线状态（每 3 秒只读轮询）、固件、电量、最后在线时间与密钥掩码。
- 指令：表情（8 种）、动作（9 种）、音量滑块、文本播报（200 字上限）；下方显示最近指令记录（待执行/已下发/已完成/失败）。
- 唤醒词：控制台下发中文或拼音，服务端转拼音，设备运行时生效并写入 NVS；无效词被拒绝且保留原词。
- 语音角色：每台设备绑定一个角色，换角色清空设备专属会话。

### FR6 语音交互
- 设备喊唤醒词即可对话；回答播放期间再说唤醒词可打断并立刻进入下一轮聆听。
- 一轮回答播完后不必再喊唤醒词即可接着说，安静超过 4 秒回到待机。
- 设备上传完整 PCM（16kHz/16bit/单声道，30 秒上限）；服务端依次完成 ASR → 角色模型流式回复 → 按句 TTS → 边合成边下发。
- 语音凭据按账号加密存储（同模型密钥方案），未配置时回落平台默认。

### FR7 会议纪要
- 长时间录音 → 说话人分离转写 → 摘要与待办。
- 录音归账户私有。

### FR8 Agent 动态
- Codex 请求批准时：机器人播报 + 手机通知；控制台「代理」页可远程允许或拒绝。
- 每次决定留痕（decision / decided_at / decided_from）。
- 电脑凭据一次性签发、可随时吊销。

### FR9 多端形态
- 网页：响应式 SPA，HttpOnly Cookie。
- Android：原生 WebView 壳，首次启动选服务器地址。
- Windows：Electron 壳，本机自动拉起 Node 后端，也可指远端。
- 小程序：Bearer token + wx.request 分块读 SSE。
- 所有端访问同一套 /api/*，数据严格隔离，客户端外壳不复制业务逻辑。

## 4 非功能需求

- HttpOnly cookie / hashed session / CSRF origin / 合理限流。
- HTTPS provider 无私网 / 用户信息 / 重定向。
- 生产环境未配置加密密钥时拒绝服务。
- 设备密钥接口按来源地址限流，防短码在线枚举。
- 验收宽度：360 / 390 / 768 / 1024 / 1440，无水平溢出与遮挡。
