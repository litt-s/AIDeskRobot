## 整理口径

以下根据项目九文档和 Git 历史回顾，不是逐日在线打卡，不把缺少的日期、工时和沟通内容补写为事实。本次工作区有会议纪要等未提交改动，完整源码包按当前文件整理，Git 基线另见证据索引。

## 2026-10-13 控制台基础

T001–T006 建立 React、Hono、D1 骨架和九文档，实现账户、模型、角色和 OpenAI 兼容流式聊天。安全基线包含加盐密码派生、会话令牌哈希、模型密钥加密、用户隔离、Origin 校验与供应商出站限制。T007–T010 继续完善局域网访问、生成可靠性和上线前检查。

## 2026-10-14 会话与设备闭环

T011–T013 实现数据库持久暂停与继续、键盘输入、自动滚动、撤销和重新生成。T014–T017 建立 devices/device_commands 与 robot_cloud 协议。历史记录明确出现 device channel online，表情、动作和音量有真机回执。舵机不动最终定位为供电不足，而非固件板型错误。T018 增加 ASR、模型和 TTS 的服务端编排，T020–T024 完善配网、长按 BOOT、自动刷新与取消。

## 2026-10-15 语音与多端

T025–T027 完成 Cloudflare 部署、GitHub 托管及提交约定。T028 移除 AIUI。T030–T033 改进连续对话、唤醒打断、自定义唤醒词和延迟。T034 增加 CloudBase Node 容器运行形态，保留 Worker 入口。T035 产出图标，T036–T038 增加 Android、PC 与小程序。T039 记录公网语音卡顿的吞吐诊断与调整。历史数值只代表当时指定环境。

## 2026-10-16 Agent 与弱网问题

T041 修复流读取长时间等待导致 busy 不清、操作按钮隐藏的问题。T042 建立事件上报、短播报、手机提醒与心跳。T043 实现命令级批准与拒绝，历史记录包含允许后文件创建、拒绝后文件不产生的证据。T044 根据录音墙钟与样本损失定位上传阻塞，默认回到整段录音上传；仍保留真机复验事项。
