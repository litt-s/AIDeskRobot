# 签名证书与多端分发说明

## Android

工程包名 cn.aidesk.console。使用 Java 17 与工程指定 Gradle/Android SDK 运行 gradle assembleDebug 可生成调试 APK；历史 CI 已构建过，不代表本包附带可安装 APK。正式 release 需要开发者自己的 keystore、alias 和密码，签名文件与密码不入仓库。本次不生成、更换或伪造发布证书。

## Windows

本次交付的 Windows 启动包直接运行 Node 后端与浏览器 UI，未做安装程序和代码签名。Electron 工程位于源码 desktop/main.cjs，可按 package.json 打包。旧 Electron 产物不计入本次构建验证，正式分发应申请自己的代码签名并重测。

## 微信小程序

使用自己的开发者 AppID 与后台合法域名，上传和审核由微信渠道完成，不使用 Android 证书。本包不携带原机私有 project.private.config.json。

## 鸿蒙

AIDesk 目前没有已验证的鸿蒙原生工程，不包含 HAP。模板中的 HAP 与本项目无关。
