# 个人 Skills 与可复用流程清单

项目名称：AIDesk 基于 ESP32 的办公陪伴机器人及多端控制台

编制日期：2026-10-23。个人信息以选题申报表、开题报告和答辩 PPT 中的填写内容为准。

## 一 清单口径

本清单描述 AIDesk 中有证据的工程能力与可复用流程。它不是模板作者的已安装 Skill 清单，也不声称以下每项都已发布成 Codex SKILL.md。正式提交时可依据本人实际使用补充课程要求的技能链接和练习证明。

## 二 工程能力

1. 需求与记忆管理：以九文档、编号任务、验收记录控制范围，产出 PRD 与开发日志。
2. 统一 API 与运行时适配：Hono 业务在 Worker/D1 与 Node/SQLite 之间复用，产出 server/node 适配层。
3. 多端复用：WebView/Electron 承载既有 Web，小程序独立网络层，共享服务端契约。
4. 流式恢复：SSE、token、lease、CAS 和 checkpoint，覆盖暂停、续写、旧请求竞态。
5. 设备接入：一次性设备码、轮询、状态上报和 ack，产出 robot_cloud 与设备测试。
6. 语音协议诊断：PCM、ASR 帧、JSON/PCM 分帧与墙钟/吞吐日志。
7. 凭据与租户隔离：服务端 AES-GCM、哈希 token、按 user_id 授权与安全错误摘要。
8. 测试与可观测性：Vitest、隔离库集成、模拟设备、错误落库、手机心跳。
9. 远程批准：事件上报、一次决定、过期拒绝、超时不干预和审计。
10. 成果材料：对照模板编写 Markdown、原型、Word 报告、PPT、截图与视频。

## 三 本次实际使用的文档技能

使用 documents 技能读取和复刻开题报告结构，使用 presentations 技能处理 5 页模板答辩材料；来源是当前 Codex 环境的内置技能。它们支持本次材料整理，不证明本人此前已掌握或独立编写同名技能。
