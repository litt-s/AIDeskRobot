# AIDesk 应用描述

应用名称：AIDesk 机器人工作台。

短描述：统一管理模型、角色与 ESP32 机器人，让桌面设备通过安全服务完成对话与指令。

完整描述：AIDesk 提供中文响应式控制台，支持账户登录、模型连接、角色设定、流式会话、暂停续写、设备绑定、状态查看与指令回报。配置有效语音服务后，可结合 ESP32 机器人进行语音对话。Android、桌面端和微信小程序使用统一业务接口。当前会议模块提供文本整理与纪要生成入口；Agent 动态用于任务通知和明确授权的命令决策。

适用人群：桌面机器人使用者、开发者与课程演示人员。需自备匹配的 ESP32 硬件及有效第三方模型/语音服务。仅用 Web 聊天不要求连接硬件。
