# 后端部署与多端数据方案

本项目以同一个服务地址、同一个用户账户实现各客户端访问同一套业务数据。Web、Android 和 Electron 远端模式使用同源会话，小程序使用 Bearer 通道。不同服务地址和独立本机 SQLite 没有自动同步机制。

两种历史运行形态是 Cloudflare Worker+D1 和 CloudBase Node 容器+SQLite。本次可运行包是独立 Node 本地实例。当前 CloudBase 数据未迁入 SQL 型持久数据库，不能将“CloudBase 托管”写作“已实现持久云数据库”。

现有部署只能走仓库 node scripts/deploy-cloudbase.mjs：拉取线上一致快照、重建种子、打包已提交代码和种子、发布。种子和快照敏感，不随成果交付。这个流程只缩小丢失窗口，不能保证发布或重启零丢失。

后续应单独选择并验证持久数据库/存储方案，完成迁移、数据校验、凭据保持与回滚。新建云资源仍需明确授权。本次没有执行部署、线上探针或数据迁移，历史域名可达性不代表今天的可用性。
