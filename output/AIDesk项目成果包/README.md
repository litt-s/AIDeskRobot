# AIDesk 项目成果包

本成果包按参考包的 13 个目录组织，内容依据 AIDesk 当前工作区、九份项目记忆、源码与实际测试整理。编制日期为 2026-10-23。原参考文件夹未被修改。

先阅读“00_待填写位置清单.md”，再按需要查看各目录。个人信息统一待填写；视频由用户自行加入，本包没有生成或附带视频。

## 目录与用途

1. 01_选题申报表：选题说明，提供 Markdown 和可编辑 Word。
2. 02_需求规格说明书与原型：需求规格、功能验收与可点击离线界面原型。
3. 03_AI能力筑基与工具链报告：AI 实操、工具配置与协作边界。
4. 04_架构设计文档：架构、技术栈、设计、数据模型、空库 SQL、功能图和架构图。
5. 05_开发日志与AI使用日志：历史开发摘要、AI 使用回顾和证据索引。
6. 06_个人Skills清单：工程能力与可复用流程，区分实际技能与待沉淀方法。
7. 07_可运行App：Windows 空库启动包、当前源码快照、Web 构建和签名说明。
8. 08_测试报告：本次99项本地测试的原始结果、测试源码和未验证项。
9. 09_上架材料包：描述、图标、截图、隐私政策草案和发布缺口。
10. 10_总结报告：成果、验证、问题与后续计划。
11. 11_答辩PPT与演示视频：5页可编辑PPT及用户自备视频放置说明。
12. 12_开题报告初稿：沿用参考包版式的6页Word开题报告及两张系统图。
13. 13_简历项目素材：可核实项目表述、STAR素材、图标与截图。

## 快速使用

查看原型：双击“02_需求规格说明书与原型/prototype.html”，顶部切换页面，离线可看。

运行应用：双击“07_可运行App/Windows启动包/启动AIDesk.cmd”，浏览器打开 http://localhost:45715。首次注册自己的账号；模型与语音功能需要自己的服务凭据。Node运行时已随包提供，不需另装Node才能使用此启动包。本机数据保存在启动包data目录，实际使用后不要将data和密钥再公开分发。

添加视频：把已拍摄视频复制到“11_答辩PPT与演示视频”，建议名“AIDesk项目演示.mp4”。如需要再在简历目录放一份。
